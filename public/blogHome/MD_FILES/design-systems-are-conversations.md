# Design systems are conversations

A design system is more than a collection of tokens and components. It is a shared language between the people shaping an experience.

## Shared language

When design and engineering use the same vocabulary, decisions become faster and more precise. A button is not merely a color and a border; it has states, intent, and a place in the product hierarchy.

## Make the rules visible

Document the decisions that are easy to forget: when to use a component, what happens when content is long, and which states need special treatment.

```css
.button {
  min-height: 44px;
  padding-inline: 1rem;
  transition: background-color 160ms ease;
}
```

The system gets stronger every time a team member can make a good decision without asking for permission.
